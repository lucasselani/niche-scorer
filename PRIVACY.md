# Privacy Policy — Niche Scorer

Last updated: September 26, 2026

Niche Scorer is a private, internal command-line research tool operated by Lucas Selani (contact: selani.lucas@gmail.com). It runs only on the operator's own computer and has no external users.

## YouTube API Services

Niche Scorer uses YouTube API Services. By using this tool, the operator agrees to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms). Google's Privacy Policy applies to data obtained through YouTube API Services: http://www.google.com/policies/privacy

## What data is accessed

The tool reads only publicly available data through the YouTube Data API v3 using an API key:

- search results for keywords chosen by the operator;
- public video metadata and statistics (title, publish date, duration, category, tags, view/like/comment counts);
- public channel metadata and statistics (title, creation date, subscriber/video/view counts).

It does not use OAuth, does not access any private or account data, and does not act on behalf of any YouTube user.

## How data is used

Data is used only to compute aggregate indicators (for example, median views per day for a topic) in a private report that informs the operator's own content planning. Data is not sold, shared, displayed publicly or redistributed.

## Storage and retention

API responses are cached locally on the operator's computer for a maximum of 24 hours to avoid duplicate requests, after which they are refreshed or deleted. Generated reports are kept privately by the operator and are deleted or refreshed within 30 days.

## Cookies and tracking

The tool has no website, does not use cookies and does not collect any information about the people whose public channels or videos appear in search results beyond the public statistics listed above.
